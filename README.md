# Piedra, Papel o Tijera - Online ✌️✊✋

Proyecto final del nivel 2 de Full Stack. Es un juego multijugador en tiempo real desarrollado con una arquitectura de monorepo, donde el backend sirve directamente los archivos compilados del frontend.

## Tecnologías utilizadas

- **Frontend:** TypeScript, Vaadin Router, Parcel.
- **Backend:** Node.js, Express, TypeScript.
- **Base de Datos:** Firebase (Firestore y Realtime Database).
- **Deploy:** Render.
